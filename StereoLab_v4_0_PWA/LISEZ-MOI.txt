STEREOLAB v4.0 — PREMIÈRE VERSION PWA

Cette archive est la v3.41 fonctionnelle équipée de la couche nécessaire
pour devenir une application installable et utilisable hors ligne.

FICHIERS
- index.html : StereoLab
- manifest.webmanifest : identité de l'application
- sw.js : fonctionnement hors ligne / cache
- icons/ : icônes d'installation
- VERSION.txt : base de version

IMPORTANT
Le mode "application installable + hors ligne" nécessite que le dossier soit
servi par une adresse HTTPS (par exemple GitHub Pages) ou par localhost pour
les tests. Ouvrir index.html directement depuis le Finder permet de voir
l'interface, mais le service worker ne peut pas s'activer en mode file://.

La prochaine étape recommandée est le déploiement de ce dossier sur GitHub
Pages. Une fois déployé, la même application pourra être installée sur les
appareils compatibles et conserver son fonctionnement hors ligne après le
premier chargement.

BASE
StereoLab v3.41. Aucun calcul acoustique n'a volontairement été modifié.
